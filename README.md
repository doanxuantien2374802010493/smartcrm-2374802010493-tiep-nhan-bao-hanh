## 1. Mô tả bài toán
Nhân viên tiếp nhận tra cứu khách hàng, ghi nhận thiết bị, phân loại nhóm sự cố, hệ thống tự động sinh hạn cam kết và theo dõi trạng thái phiếu.

## 2. Phạm vi
- Làm: Quản lý phiếu tiếp nhận, phân loại lỗi, sinh SLA.
- Không làm: Phân công kỹ thuật viên, quản lý kho linh kiện.
